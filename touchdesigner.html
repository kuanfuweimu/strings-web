实时接入 TouchDesigner

让 STRINGS 在 Web Render TOP 内运行，输出纯画面的 4K 纹理。用浏览器里的面板、MIDI 或手柄控制它，再接入你的投影、合成或录制网络。

1. 保持本地服务运行

在项目目录运行 node server.js。如果服务是在更新前启动的，请先结束旧服务再重启。本页面及控制面板都通过这个服务打开。

2. 配置 Web Render TOP

在 TouchDesigner 新建一个 Web Render TOP，将下面地址复制到 URL or File。一个服务只运行一个 TD 输出；不要同时在 Chrome 打开该输出地址。

打开 TD 控制面板
ActiveOn
Cook AlwaysOn
Output ResolutionCustom Resolution
Resolution W / H3840 / 2160
Use Global Res MultiplierOff

需要允许 4K 输出的 TouchDesigner 许可证。TD 实际输出尺寸也必须是 3840×2160；仅网页内部画布为 4K 并不能绕过 TOP 或许可证的分辨率限制。

3. 接到你的输出网络

Web Render TOP → Null TOP → 后续合成／投影输出

将 Null 命名为 null_strings，节点颜色设为 #2F59AD。保持时间线播放、输出节点被使用或 Viewer Active，防止 TD 停止烹饪。控制面板出现“TD 实时输出 · 3840×2160”后即可切换场景、调节参数。

画面与连接

这是 TD 内独立渲染的实时画面，不是 Chrome 窗口的像素复制，也不是 Spout／NDI 发送器。网页与 TD 仅传控制参数和状态，没有 JPEG 视频传输；普通浏览器控制与 TD 控制互相独立。输出为黑底，HUD 保持隐藏。

实际帧率取决于显卡、密度、TD 的 Chromium 版本及工程负载。请先检查 Web Render TOP 的 Info DAT 错误、WebGL2 和 EXT_color_buffer_float 支持。掉线时面板会提示，连接恢复后继续收发；旧按钮命令不会补发。若一直等待，检查是否有重复 TD 输出或旧版服务。

在 TD 中接 Movie File Out TOP 录制。项目原有逐帧 MP4 导出仍可使用；TD 模式不触发浏览器下载。
